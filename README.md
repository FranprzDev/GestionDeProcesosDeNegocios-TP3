# TP3 — n8n: El Futuro de la Automatización

Trabajo Práctico 3 de la materia **Gestión de Procesos de Negocios** (UTN-FRT). Presentación web sobre n8n como plataforma de automatización conectada con IA.

## Qué es

Un slide deck en un solo `index.html`: portada, el problema (la IA aislada), memoria/augmentación con datos, casos de uso y cierre. Navegación por slides con transiciones, Tailwind por CDN y tipografía Inter.

## Ver

Abrí `index.html` en el navegador. Sin build, sin dependencias.
